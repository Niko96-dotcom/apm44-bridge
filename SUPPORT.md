# Support

APM44 Bridge is an open-source project for macOS users who want 44.1 kHz DAW
sessions while monitoring through AirPods Max USB-C at 48 kHz.

## Getting Help

- Install and daily use: `docs/install.md`
- Cubase first run: `docs/first-run-cubase.md`
- Release and notarization: `docs/release.md`
- HAL driver details: `docs/hal-driver.md`

For bugs, use the GitHub bug report template and include:

- macOS version
- DAW and version
- whether you are using the HAL device or BlackHole fallback
- output of `bash scripts/verify-devices.sh`
- output of `bash scripts/verify-hal-driver.sh`

Please do not post Apple Developer credentials, notary logs containing account
details, or private certificate files.
