<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| maintainer shell -> keychain | Release scripts query local signing identities and choose which certificate signs a public package. |
| build artifacts -> public package path | Local app/driver payload becomes a user-installable package artifact. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-46-01 | Spoofing | `scripts/build-release-pkg.sh` installer identity resolver | mitigate | Require `Developer ID Installer:` prefix, exact keychain match, and fail on zero or multiple matches. |
| T-46-02 | Tampering | final `$APM44_PKG_PATH` | mitigate | Remove stale package paths before build and never move unsigned package bytes to the public final path. |
| T-46-03 | Information Disclosure | certificate/private-key setup | mitigate | Error messages point to CSR/import helpers; no certificate, private-key, or `.p12` material is written by this plan. |
</threat_model>
