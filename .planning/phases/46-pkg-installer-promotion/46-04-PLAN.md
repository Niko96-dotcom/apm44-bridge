<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| package scripts -> system paths | Installer scripts run with elevated privileges and replace `/Applications` and HAL driver paths. |
| verifier -> installed system | Optional install-smoke mode writes system install locations and reloads Core Audio through existing scripts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-46-11 | Tampering | generated `preinstall` script | mitigate | Remove only exact APM44 app and HAL driver paths before payload install; tests assert exact strings. |
| T-46-12 | Denial of Service | generated `postinstall` script | mitigate | Fail if app or driver path is missing after install; keep Core Audio reload and app open best-effort. |
| T-46-13 | Repudiation | package provenance | mitigate | Write `$PKG.provenance.txt` with package hash, git head, helper build ID, deterministic app bundle hash, and driver executable hash. |
| T-46-14 | Elevation of Privilege | `APM44_RUN_PKG_INSTALL_SMOKE=1` | mitigate | Default verifier is non-destructive; install smoke requires explicit env var and then runs existing installed-sync/HAL checks. |
</threat_model>
