<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| release orchestration -> artifact consumers | Later phases rely on artifacts emitted by `release-all.sh` being public-release validated. |
| local-only override -> public claims | Maintainer may run unnotarized local packaging, but those artifacts must not be represented as public output. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-46-08 | Tampering | `scripts/release-all.sh` release order | mitigate | Build/notarize public PKG only after app/driver staple validation and before downstream DMG packaging. |
| T-46-09 | Repudiation | optional `APM44_BUILD_PKG` branch | mitigate | Remove optional public package branch so normal release logs always include package build and validation. |
| T-46-10 | Spoofing | local-only unnotarized override | mitigate | Print explicit `LOCAL-ONLY UNNOTARIZED: skipping public PKG gate` and avoid public package claims in override mode. |
</threat_model>
