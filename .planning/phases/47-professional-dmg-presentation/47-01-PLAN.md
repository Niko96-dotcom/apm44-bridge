# Plan 47-01: PKG-first final DMG and layout gate

## Objective

Make the final package-only DMG a professional installer wrapper: top-level validated PKG plus readme, no raw app, HAL driver, or command installer internals.

## Tasks

1. Add tests and a verifier for final DMG layout.
   - Fake `hdiutil create` in `tests/test_release_scripts.sh`.
   - Add `run_dmg_pkg_first_layout_check` proving package-only staging contains the PKG and excludes raw internals.
   - Add `run_verify_release_dmg_layout_check` proving the verifier rejects old raw staging and accepts PKG-first staging.

2. Update final DMG creation and orchestration.
   - In `scripts/build-release-dmg.sh`, when `APM44_DMG_PACKAGE_ONLY=1`, require the validated PKG and stage only the PKG plus readme.
   - Create `scripts/verify-release-dmg-layout.sh` with staging and mounted-DMG inspection modes.
   - In `scripts/release-all.sh`, run the layout verifier after package-only DMG creation and before DMG notarization.

3. Complete the final DMG byte gate.
   - In `scripts/notarize-release-dmg.sh`, run `spctl --assess --type open --context context:primary-signature --verbose=4 "$DMG"` after stapler validation and before checksum.

## Verification

- `bash tests/test_release_scripts.sh`
- `bash scripts/ci.sh`

## Success Criteria

- Package-only DMG staging contains a single obvious `.pkg` install object and no raw app, driver, or command installer.
- Release orchestration verifies layout before notarizing the final DMG.
- DMG checksum is generated only after notary acceptance, stapling, stapler validation, and Gatekeeper assessment.
