## Phase Goal

**As a** music producer running a DAW at 44.1 kHz, **I want to** build and launch a console bridge binary, **so that** later plans can connect BlackHole input to AirPods output without a custom driver.

<objective>
Bootstrap the greenfield repo: CMake 3.28+ monorepo, `Shared/` format helpers, `BridgeDaemon/` CLI skeleton (`apm44-bridge`), and a minimal unit test target.

Purpose: Establish agent-friendly build + module boundaries before HAL code lands.
Output: Compilable `apm44-bridge` that parses CLI and exits; `apm44_shared` static lib; README build instructions.
</objective>

Create root `CMakeLists.txt` with `cmake_minimum_required(VERSION 3.28)`, `project(APM44Bridge VERSION 0.1.0 LANGUAGES CXX)`, `set(CMAKE_CXX_STANDARD 20)`, `MACOSX_DEPLOYMENT_TARGET=14.0`, `add_subdirectory(Shared)` and `add_subdirectory(BridgeDaemon)` (BridgeDaemon added in Task 2).

`Shared/` static target `apm44_shared`:
- `AudioFormats.h`: helpers `MakeFloat32StereoNonInterleaved(sampleRate)` returning `AudioStreamBasicDescription` with `kAudioFormatLinearPCM`, `kAudioFormatFlagIsFloat | kAudioFormatFlagIsNonInterleaved`, 2 channels, 32-bit, appropriate `mSampleRate`.
- Constants `kInputSampleRate = 44100.0`, `kOutputSampleRate = 48000.0`.
- `RtConstraints.h`: comment-only documentation of IOProc forbidden operations (malloc, locks, log, file I/O) for executor reference — per ENG-05 / CONTEXT RT safety.

Link `CoreAudio` and `AudioToolbox` frameworks to `apm44_shared` (needed for ASBD types).

Add `.gitignore` entries: `build/`, `.cxx/`, `cmake-build-*`, `.DS_Store`.
  </action>
