## Phase Goal

**As a** producer using APM44 Bridge, **I want** a menu bar control to start and stop the bridge daemon, **so that** I can monitor on AirPods without running Terminal commands.

<objective>
Add **machine-readable metrics stream** for the Swift app: periodic JSON lines on stdout from the main thread, plus relax `--target-fill-ms` clamp to **6–40** so CONTEXT Low preset (8 ms) and ROADMAP (~6–8 ms) are valid.

Purpose: Enable APP-05 meters and QA-03 honest latency without RT logging.
Output: `--metrics-json` flag, `BridgeMetrics` helper, ctest coverage.
</objective>
