# Plan 12-01: CI dry-run for installed-sync and full automated gate run

## Objective

`scripts/ci.sh` must run `scripts/verify-installed-sync.sh --dry-run`
as a non-hardware gate (QA-01), and we must produce a
`12-AUTOMATED-VERIFICATION.md` artifact that captures the full
automated verification output (QA-02).

## Tasks

### Task 1: Wire `verify-installed-sync.sh --dry-run` into `ci.sh`

**Type:** auto
**Files:** `scripts/ci.sh`

After the Swift app build (or after the Swift unit tests, if
`xcodegen` is unavailable), invoke the dry-run check. The
dry-run is non-fatal — the existing script returns 0 with a
`WARN:` line when the embedded helper is missing. CI must
*surface* the WARN, not silently pass it.

Concretely, add a new step after the Swift unit tests:

```bash
echo "== Installed-sync dry-run =="
bash scripts/verify-installed-sync.sh --dry-run
```

Place it after the Swift unit tests and before the final
`echo "ci: OK"`. Wrap it in a `command -v bash` guard is not
necessary — `bash` is always present in the dev environment.

### Task 2: Run the full CI gate and capture the output

**Type:** auto
**Files:** (none modified)

Run `bash scripts/ci.sh` and capture the stdout + stderr to
`/tmp/ci.log`. Verify the log shows:

- "Secret scan" — `OK`
- "Configure CMake" — no errors
- "Build native targets" — no errors
- "Native tests" — `100% tests passed`
- "Swift app build" — no errors (if xcodegen is present)
- "Swift unit tests" — no failures (if xcodegen is present)
- "Installed-sync dry-run" — `OK` or `WARN` (no failure)
- `ci: OK` at the end

Save the log to
`.planning/phases/12-verification-closure/12-ci-run.log` and
summarise the key pass/fail lines in the
`12-AUTOMATED-VERIFICATION.md` artifact.

### Task 3: Write `12-AUTOMATED-VERIFICATION.md`

**Type:** auto
**Files:** `.planning/phases/12-verification-closure/12-AUTOMATED-VERIFICATION.md`

Produce a markdown file with:

- Header: phase, plan, date, command (`bash scripts/ci.sh`).
- Section "CI steps and results" — table of (step, status,
  notes) for each of: secret scan, cmake configure, native
  build, ctest, swift build, swift tests, installed-sync
  dry-run.
- Section "Test summary" — the totals from ctest and xcodebuild.
- Section "Deviations" — anything that diverged from
  `12-CONTEXT.md` (e.g., xcodegen not present, etc.).
- Section "Verification" — links the full log file.

## Success criteria

- `scripts/ci.sh` ends with a call to
  `bash scripts/verify-installed-sync.sh --dry-run`.
- A full `bash scripts/ci.sh` run completes with `ci: OK`.
- `12-AUTOMATED-VERIFICATION.md` exists and lists each gate
  with a pass/fail result.

## Output

Per-task commits prefixed `chore(ci):` (Task 1) and
`docs(12):` (Task 3). `12-AUTOMATED-VERIFICATION.md` plus the
captured log.
