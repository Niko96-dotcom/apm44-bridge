# Plan 11-01: Shm size validation before header/capacity trust

## Objective

`MmapShmRing::open()` must reject objects smaller than
`ShmRingHeader` before reading any header field, and reject valid-looking
headers whose mapped object is smaller than
`ShmTotalSize(capacity_frames)`. The live generation staleness check
must also compare object size, not just st_dev/st_ino, so a HAL driver
that grew the ring (or a stale object with the wrong size) is detected.

## Tasks

### Task 1: Add new error codes for size mismatches

**Type:** auto
**Files:** `Shared/include/apm44/MmapShmRing.h`

Add two new entries to the `ShmRingErrorCode` enum:

```cpp
enum class ShmRingErrorCode {
  None,
  OpenFailed,
  CreateFailed,
  PermissionFailed,
  TruncateFailed,
  StatFailed,
  EmptyObject,
  MapFailed,
  InvalidHeader,
  HeaderTruncated,         // SHM-01
  CapacityExceedsObject,   // SHM-02
};
```

### Task 2: Reject truncated objects in `MmapShmRing::open`

**Type:** auto
**Files:** `Shared/src/MmapShmRing.cpp`

In `open()` after the `fstat` succeeds (so we know `st_size > 0`),
add a size check **before** the `mmap` call:

```cpp
if (static_cast<std::size_t>(st.st_size) < sizeof(ShmRingHeader)) {
  close();
  recordError(ShmRingErrorCode::HeaderTruncated,
              "shm object is smaller than ShmRingHeader: " +
                  std::to_string(st.st_size) + " bytes");
  return false;
}
```

This means we never even `mmap` an object too small to contain a
header. Update the early `fstat` failure branch to also handle
the `<= sizeof(ShmRingHeader)` case so the diagnostic is precise.

### Task 3: Reject headers whose capacity exceeds the mapped object

**Type:** auto
**Files:** `Shared/src/MmapShmRing.cpp`

In `open()` after `mmap` and after `ValidateShmHeader(*header_)` passes,
add a second size check:

```cpp
const std::size_t declaredTotal =
    ShmTotalSize(header_->capacity_frames);
if (static_cast<std::size_t>(st.st_size) < declaredTotal) {
  const std::string message =
      "shm object too small for declared capacity: mapped " +
      std::to_string(st.st_size) + " bytes, header declares " +
      std::to_string(declaredTotal) + " bytes";
  close();
  recordError(ShmRingErrorCode::CapacityExceedsObject, message);
  return false;
}
```

This protects against a producer that writes a syntactically valid
header but lies about capacity (e.g., a freshly created object that
was truncated, or an attacker-crafted header).

### Task 4: Include size in `ShmObjectIdentity`

**Type:** auto
**Files:** `Shared/include/apm44/ShmObjectIdentity.h`,
`Shared/src/MmapShmRing.cpp`

Add `std::size_t size = 0;` to `ShmObjectIdentity`. Update
`CaptureMappedIdentity` to capture the size from the fstat result
(`st.st_size`). Update `isMappedObjectStale` (and any
`ShmObjectIdentityChanged` helper) to compare sizes — if the
current size differs from the captured mapped size, the object is
stale. This implements SHM-03: a live driver generation read
detects a size change before re-mapping.

### Task 5: Build and run existing tests

**Type:** auto
**Files:** (none modified)

Run the existing `test_mmap_shm_ring`, `test_shm_object_identity`,
and `test_shm_stale_recovery` to ensure the new error codes and
size comparison do not break the existing happy paths.

## Success Criteria

- `MmapShmRing::open()` on an object smaller than
  `sizeof(ShmRingHeader)` returns `false` with
  `lastErrorCode == HeaderTruncated` (SHM-01).
- `MmapShmRing::open()` on a valid-header object whose
  `capacity_frames` would exceed the mapped size returns `false`
  with `lastErrorCode == CapacityExceedsObject` (SHM-02).
- A live generation read on an object whose size has changed
  since the last `open()` returns `isMappedObjectStale() == true`
  (SHM-03).
- Existing tests still pass.
