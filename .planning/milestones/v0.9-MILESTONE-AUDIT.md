## Integration Review

- ASBD validation now rejects packet/frame layouts before IOProc code trusts
  interleaved or non-interleaved buffer memory.
- Shared-memory open validation now treats fixed 44.1 kHz sample rate and build
  ID agreement as hard compatibility checks, matching release/security docs.
- Public docs and release-script checks agree on the 0.1.1 artifact identity,
  Safe as the fresh-install latency default, and
  `build/Driver/APM44Bridge.driver` as the HAL driver build path.
- `scripts/release-all.sh` now verifies release codesigning before the normal
  notarization path continues.
- `.github/workflows/sign-notarize.yml` is explicitly release evidence, not an
  authoritative public DMG publication path.
