## Pillar 1 — Layout

### Shell

| Property | Value |
|----------|-------|
| Container | `MenuBarExtra("APM44 Bridge", systemImage: …)` — label hidden in menu bar, icon-only in status area |
| Popover width | **320 pt** fixed (default); min height **auto**; max content height **420 pt** then internal scroll |
| Padding | **16 pt** outer inset on all popover content |
| Section gap | **16 pt** between major sections |
| Divider | `Divider()` between **Control**, **Monitoring**, **Footer** groups |

### Vertical structure (top → bottom)

```
┌──────────────────────────────────────┐  16pt pad
│ Status row (icon + Running/Stopped)  │
│ Output device (picker, full width)   │  Control
│ Latency mode (segmented, full width) │  section
│ [Start Bridge] or [Stop Bridge]      │
├──────────────────────────────────────┤
│ ~XX ms monitoring latency (prominent)│  Monitoring
│ Buffer fill bar + numeric fill ms    │  section
│ Glitches row (count + indicator)     │
│ Effective ratio (caption, mono)      │
├──────────────────────────────────────┤
│ Hotplug / error banner (if active)   │  inline
├──────────────────────────────────────┤
│ Version · Open docs (caption links)  │  Footer
└──────────────────────────────────────┘
```

### Alignment

- All controls: **leading** alignment, **full width** where applicable (`frame(maxWidth: .infinity, alignment: .leading)`).
- Meters: label left, value right on same row (HStack, `Spacer()`).
- Primary action button: **full width**, min height **28 pt** (comfortable click target).

### Menu bar icon (status area)

- Single template image; state conveyed by **tint** + optional **badge** (dot) — see Pillar 3.
- Tooltip (accessibility description): includes bridge state + selected output device name (truncated to 40 chars).

## Pillar 2 — Components

| ID | Component | SwiftUI / API | Behavior |
|----|-----------|-------------|----------|
| C1 | **Status row** | `HStack` + `Image` + `Text` | Shows textual state: "Running", "Stopped", "Starting…", "Error" |
| C2 | **Output device picker** | `Picker` (`.menu` style) | Lists output-capable devices; prefer AirPods/USB in sort order; persist UID in `UserDefaults` key `apm44.outputDeviceUid` |
| C3 | **Latency preset** | `Picker` segmented **or** `Picker` radio group | Three options only; maps to daemon flags (table below) |
| C4 | **SRC quality** (APP-03) | Bound to preset by default; optional **disclosure** "Advanced" reveals `Picker` for medium / high / best | Changing preset updates both fill + SRC unless user overrode SRC in session |
| C5 | **Start / Stop** | `Button` (primary) | Start disabled when no valid output device; Stop disabled when not running |
| C6 | **Honest latency label** | `Text` `.headline` or `.title3` | Always visible when running; static formula copy when stopped (see Copywriting) |
| C7 | **Buffer fill meter** | `ProgressView(value:)` or custom `GeometryReader` bar | Normalized 0…1 from `fillMs / targetFillMs`; show numeric `fillMs` to 1 decimal |
| C8 | **Glitch indicator** | `HStack` + SF Symbol `waveform.badge.exclamationmark` | Shows cumulative `xruns`; accent pulse on increment (Pillar 4) |
| C9 | **Effective ratio** | `Text` `.caption` `.monospacedDigit()` | Displays effective SRC ratio from metrics JSON |
| C10 | **Banner** | `HStack` + icon + message | Hotplug reconnect, spawn failure, device missing |
| C11 | **Footer links** | `Link` or `Button` `.plain` | Version string; "Routing help" opens bundled/README URL |

### Latency preset → daemon mapping

| Preset | UI subtitle (shown under control) | `--target-fill-ms` | `--src-quality` | ROADMAP band |
|--------|-----------------------------------|--------------------|-----------------|--------------|
| **Low** | ~10–12 ms buffer | **10** (CLI floor; aligns ~6–8 ms intent via minimum stable fill) | `medium` | ~6–8 ms target |
| **Balanced** (default) | ~12–18 ms buffer | **15** | `medium` | default |
| **Safe** | ~25–40 ms buffer | **30** | `best` | Safe mixing |

**Planner note:** If product requires true 8 ms Low, extend daemon CLI lower bound in Phase 3; until then UI uses **10 ms** per `CliOptions.cpp`.

### SRC quality labels (advanced picker)

| CLI value | User-facing label |
|-----------|-------------------|
| `medium` | Standard |
| `high` | High |
| `best` | Best (higher CPU) |

### Daemon integration (non-UI but contract)

- Spawn `apm44-bridge` with resolved args; parse **JSON lines** on background queue (500 ms UI poll).
- Metrics fields required in contract: `fillMs`, `targetFillMs`, `xruns`, `effectiveRatio`, `estimatedLatencyMs` (or UI computes from documented constants per CONTEXT).
- No HAL / driver UI in this phase.

## Pillar 3 — States

### Menu bar icon

| State | Tint | SF Symbol (template) | Badge |
|-------|------|----------------------|-------|
| Stopped | `secondary` / gray | `headphones` | none |
| Running | `green` (semantic) | `headphones` | none |
| Error | `red` | `headphones.circle.fill` or `exclamationmark.triangle.fill` | optional red dot |

### Bridge lifecycle (in-popover)

| State | C5 label | C1 text | C6 latency | C7 meter |
|-------|----------|---------|------------|----------|
| Stopped | Start Bridge | Stopped | Shows explanatory static copy | Hidden or dimmed "—" |
| Starting | Stop Bridge (disabled) | Starting… | "Measuring…" | Indeterminate progress |
| Running | Stop Bridge | Running | `~{N} ms monitoring latency` | Live updates |
| Stopping | Start Bridge (disabled) | Stopping… | Last value grayed | Frozen |
| Error | Start Bridge | Error | Hidden or "Unavailable" | Hidden |

### Meter semantics

| Fill level | Bar color | Label |
|------------|-----------|-------|
| 40–160% of target | `accentColor` / system accent | Normal |
| <40% or >160% of target | `orange` | "Buffer low" / "Buffer high" |
| `xruns` increased since last poll | Glitch row **accent** + symbol | "Glitch detected" (clears after 2 s unless count still rising) |

### Hotplug (APP-04)

| Event | Banner (C10) | Action |
|-------|----------------|--------|
| Output device vanished | "Output disconnected — select a device" | Stop bridge if running |
| Output reappeared (debounced 1 s) | "Reconnecting to {name}…" | Auto-restart if was running |
| Restart failed | Error state + banner | User must Start manually |

### Empty / edge

| Condition | UI |
|-----------|-----|
| No output devices | C2 shows "No output devices"; C5 disabled; banner with setup hint |
| Daemon binary missing | Error icon; banner "Bridge not found — build or install apm44-bridge" |
| Metrics stale (>2 s) | Caption "Metrics stale" in monitoring section |

## Pillar 4 — Motion

| Interaction | Motion rule |
|-------------|-------------|
| Popover open/close | **System only** — no custom transition |
| Meter fill | Value changes at **500 ms** poll; optional **linear** 200 ms animation on bar width — **disabled** when `accessibilityReduceMotion` |
| Glitch pulse | On `xruns` increment: single **opacity 1.0 → 0.6 → 1.0** over **300 ms** on C8 row — **disabled** when Reduce Motion |
| Banner appear | `.transition(.opacity)` **150 ms** |
| Button press | System default button animation only |
| Icon state change | **No** cross-fade; instant tint/symbol swap |

**Prohibited:** bounce, spring, parallax, or celebratory motion on start/stop.

## Pillar 5 — Tokens

### Spacing scale (multiples of 4)

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4 pt | Icon–text gap in status row |
| sm | 8 pt | Inline row padding, segmented control internal |
| md | 16 pt | Section padding, between sections |
| lg | 24 pt | Rare; only if footer needs breathing room |
| xl | 32 pt | Not used in popover |

**Exceptions:** Menu bar touch targets — primary button **min height 28 pt** (≥44 pt not required for macOS menu extras per HIG, but button must meet comfortable click).

### Typography

| Role | Size | Weight | Line height | SwiftUI style |
|------|------|--------|-------------|---------------|
| Body | 13 pt | regular (400) | 1.5 | `.body` |
| Label | 11 pt | regular (400) | 1.4 | `.caption` |
| Section heading | 13 pt | semibold (600) | 1.2 | `.headline` |
| Latency display | 15 pt | semibold (600) | 1.2 | `.title3` |

Use **only** these four roles in the popover. No custom font families.

### Color (60 / 30 / 10 — semantic, light & dark)

| Role | Light | Dark | Usage (60/30/10) |
|------|-------|------|------------------|
| Dominant (60%) | `NSColor.windowBackgroundColor` | same semantic | Popover background |
| Secondary (30%) | `controlBackgroundColor` | same semantic | Grouped rows behind meters; picker backgrounds |
| Accent (10%) | `controlAccentColor` | same semantic | **Only:** primary Start button fill, running icon tint, fill bar normal state, glitch pulse |
| Destructive | `systemRed` | same | Stop Bridge label when running (outline/role `.destructive`), error icon, error banner |

**Accent reserved for:** Start Bridge (primary), running menu bar tint, buffer bar (healthy), glitch highlight — **not** for picker chrome, device name, or body text.

**Destructive reserved for:** Stop Bridge, error states, disconnect warnings — **not** for glitch count alone (use accent + symbol).

## Pillar 6 — Accessibility

| Requirement | Implementation |
|-------------|----------------|
| VoiceOver | Every control has `accessibilityLabel` + `accessibilityHint` where non-obvious (e.g. latency: "Estimated round-trip monitoring latency, not zero") |
| State not color-only | Running/stopped/error announced in C1 text; icon tint is supplementary |
| Keyboard | Popover focus order: device → latency → advanced SRC → primary button → footer links; **Esc** closes popover (system) |
| Dynamic Type | Support up to **Accessibility Large** for body/caption; latency line may wrap to two lines; popover scrolls |
| Reduce Motion | Disable meter interpolation and glitch pulse (Pillar 4) |
| Honest latency (QA-03) | VO reads full string including "~" and "monitoring latency"; never "zero latency" in any label |
| Contrast | Use system semantic colors only — no custom low-contrast grays |

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (stopped) | **Start Bridge** |
| Primary CTA (running) | **Stop Bridge** |
| Empty devices heading | **No output devices** |
| Empty devices body | Connect headphones or an audio interface, then choose an output here. |
| Error state (spawn) | **Bridge could not start.** Check that apm44-bridge is installed and BlackHole is set to 44.1 kHz. |
| Error state (metrics) | **Lost connection to bridge.** Stop and start again. |
| Latency (running) | **~{N} ms monitoring latency** — `{N}` from metrics; prefix `~` always |
| Latency (stopped) | **Monitoring adds latency** — About {presetRange} ms in {presetName} mode when running. |
| Hotplug banner | **Reconnecting to {deviceName}…** |
| Destructive confirmation | **Stop Bridge:** none (immediate stop; audio path is non-destructive to DAW) |
| Glitch row | **Glitches: {count}** — append **(new)** for 2 s after increment |
| Footer | **APM44 Bridge {version}** · **Routing help** |

**Prohibited strings:** "zero latency", "no latency", "real-time with no delay", "instant monitoring".
