## Phase Goal

**As a** producer using APM44 Bridge, **I want** to choose which physical output device receives resampled audio, **so that** I can target my AirPods or another USB output without editing CLI flags.

<objective>
Implement **device picker** backed by `apm44-bridge --list-devices` TSV output; persist UID in UserDefaults; restart-safe selection for hotplug (plan 03-06).

Purpose: APP-01 device name + foundation for APP-04.
Output: `DeviceCatalog`, Picker UI, spawn args include `--output-device`.
</objective>
