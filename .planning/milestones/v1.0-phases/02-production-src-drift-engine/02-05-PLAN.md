  <name>Task 2: BridgeEngine production audio path</name>
  <files>BridgeDaemon/src/engine/BridgeEngine.h, BridgeDaemon/src/engine/BridgeEngine.cpp</files>
  <action>
Refactor `BridgeEngine`:

1. **Members:** `LibSamplerateSrc src_`, `DriftController drift_`, `bool useLegacyConverter_`, `double targetFillMs_`, retain `PlanarRingBuffer ring_` and legacy `AudioConverterSrc legacyConverter_`.

2. **`prepare()`:** 
   - `targetFillFrames = PlanarRingBuffer::framesForMilliseconds(targetFillMs_, 44100.0)`.
   - Ring capacity = next power of two ≥ `max(2 * targetFillFrames + 512, 1024)` (discretion).
   - `drift_.setTargetFillFrames(targetFillFrames)`.
   - Init `src_` with quality from CLI or legacy converter from Phase 1 ASBDs.

3. **`onInput`:** push only; on full ring use same drop-oldest policy as Phase 1 OR increment `drift_.notifyOverrun()` once per block when push returns fewer than requested frames (document choice in comment — prefer notify overrun vs silent drop).

4. **`onOutput`:** 
   - Read `fill = ring_.fillFrames()`.
   - `ratio = drift_.update(fill)`.
   - `src_.setRatio(ratio)` (or legacy convert path).
   - Pop into scratch → `process` → fill HAL buffers; silence on failure; `drift_.notifyUnderrun()` when pop returns insufficient frames.

5. **RT discipline:** no logging in `onInput`/`onOutput`; extend scratch vectors in `prepare()` only.

6. **`runUntilSignal` exit:** on main thread, print `fill_ms`, `smoothedRatio`, `currentPpm`, underrun/overrun counts, xruns (existing).

**Per CONTEXT:** Input push-only; output pop+SRC; never mutex between procs.

Keep `AudioConverterSrc.cpp` in build for legacy flag.
  </action>
