<task type="auto">
  <name>Task 2: IOProcs + BridgeEngine run loop</name>
  <files>BridgeDaemon/src/engine/IoProcHandlers.h, BridgeDaemon/src/engine/IoProcHandlers.cpp, BridgeDaemon/src/engine/BridgeEngine.h, BridgeDaemon/src/engine/BridgeEngine.cpp, BridgeDaemon/src/main.cpp</files>
  <action>
`IoProcHandlers` static RT callbacks with `void* refCon` → `BridgeEngine*`:
- **Input proc:** copy non-interleaved float from `AudioBufferList` into ring via `push`; if ring full, drop newest or oldest per documented policy (document in code comment — prefer drop oldest for MVP).
- **Output proc:** pop available frames → `AudioConverterSrc::convert` → fill output `AudioBufferList`; if insufficient input or convert fails, write silence (memset 0).
- **Forbidden in callbacks:** malloc, locks, logging, file I/O, device enumeration (assert in debug only on main thread).

`BridgeEngine`:
- `prepare(BridgeDevicePair)`: preallocate all buffers, create converter, compute ring capacity (~20 ms @ 44100 ≈ 882 frames minimum — use discretion within CONTEXT 256–1024 block target).
- `start()`: `AudioDeviceCreateIOProcID` for in/out; `AudioDeviceStart` both; log device names and **actual** `mFramesPerPacket`/buffer sizes to stderr once on main thread.
- `stop()`: stop and dispose IOProcs in reverse order.
- Background: `std::atomic<uint64_t> xruns` incremented from output proc on underrun/converter fail; main thread prints stats every 5s optional or on exit only.

`main.cpp`: default run path = preflight + `BridgeEngine::run()` blocking until SIGINT; handle SIGINT/SIGTERM for clean stop.

Target block size 512 @ 44.1 where `AudioDeviceSetProperty` for buffer frame size is supported — if set fails, log actual size and continue.

**Per MVP-02:** Use AudioToolbox `AudioConverter` C API only (not AVAudioConverter / Swift).
