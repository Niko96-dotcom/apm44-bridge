# Code of Conduct

This project follows the Contributor Covenant Code of Conduct, version 2.1.

## Our Pledge

We pledge to make participation in this project a harassment-free experience for everyone.

## Expected Behavior

- Be respectful and constructive.
- Focus criticism on ideas, code, and evidence.
- Assume good intent while making space for correction.
- Keep security-sensitive or private information out of public threads.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Publishing private information without explicit permission.
- Sustained disruption of project discussions.

## Enforcement

Maintainers may remove comments, close issues, or block contributors who violate this code of conduct.
